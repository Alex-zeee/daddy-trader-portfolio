MT5 se data (CSV) nikalna
  1. MT5 mein Tools → Options → Charts mein Max bars in chart ko Unlimited karein, phir MT5 dobara kholein.
  2. Ctrl+U dabayein, Bars tab kholein.
  3. Symbol (jaise XAUUSDm), timeframe M1 aur dates chunein, phir Request dabayein.
  4. Export Bars daba kar file save karein.
  5. Yahan Upload CSV se wo file chunein. File ek dafa upload karne ke baad isi browser mein save rehti hai.

M1 ka 1 saal ka data theek chalta hai. Chhote timeframe se bade timeframe (5m, 15m, 1h, 4h, D) khud ban jate hain.
